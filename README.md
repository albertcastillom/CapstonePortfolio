# Capstone Portfolio

A dependency-free static portfolio website designed for GitHub Pages.

## Customize the site

1. Replace `Your Name` and `Your Capstone Project Title` in the HTML files.
2. Replace the instructional placeholder copy with your project narrative.
3. Add project images and diagrams to an `images/` folder, then replace each placeholder block with an `<img>` element that has useful alt text.
4. Update bibliography entries and replace placeholder links.

## Preview locally

You can open `index.html` directly in a browser or start a local server:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

Push this repository to GitHub, open **Settings → Pages**, select **Deploy from a branch**, and choose the repository's main branch and root folder.
